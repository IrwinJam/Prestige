Prestige.

The trust gateway for AI agents.

A drop-in proxy that sits between any agent and the model. It blocks hijacked tool calls and cuts token cost, and measures both on your own agent before you ship it.

By James Irwin · Prestige is a working codename, after the three acts of a magic trick: the Pledge, the Turn, the Prestige.

Why me

I spent a decade learning to steer exactly where a person's attention goes, and walk off with the thing they were guarding. A prompt injection is the same trick, aimed at a machine. I built the gateway that stops it.

Competition magician: TAOM Senior Stage Champion (as a junior) · IBM Stage Gold-Medal Finalist · youngest invitee to the FISM North American championships. Prompt injection runs on the same principle as the craft: misdirection.

Two problems, one place to fix them

Every production agent reads text someone else wrote, then calls real tools. Both problems sit at that one step.

RISK

It gets hijacked

Hidden instructions in the content an agent reads can turn its tools against the user. Prompt injection is OWASP's #1 LLM risk, and it keeps beating shipped guardrails.

COST

It burns tokens

Agents resend the same context every turn and quietly break the prompt cache, where cached input is far cheaper. The bill grows faster than the work.

GAP

Nobody proves it

Tools report cost or block attacks. Few measure both on the same runs, with the misses listed.

How it works

Point your agent at Prestige instead of the model (OpenAI-compatible, one line of config). It rewrites each request on the way out and checks each tool call on the way in.

01 / BLOCK

Origin check

A high-impact call is blocked when its destination came only from tool output, never from the user. With the confirm step on, the user is asked instead.

02 / CUT

Cache-aware cost policies

Keeps the prompt prefix stable so the provider's cache hits more often, and sets reasoning effort low. Input from cache went from 78% to 89% on Muse Spark.

03 / PROVE

Measured eval

Runs a public attack benchmark through the gateway and reports security and cost from the same runs, against a test plan written first.

The 90-second demo

A trick in three acts

One terminal. Same agent, same task, run twice.

The Pledge
# AgentDojo banking suite, a public benchmark
user> pay the bill in my files
a file the agent reads carries an injected instruction (supplied by the benchmark, not shown)

An ordinary job. The trap sits in the content the agent reads, not in the user's request. This project never writes or shows attack text.

The Turn
# without Prestige
> send_money(recipient=<never in the user's request>) ✗ BREACH

# with Prestige
> blocked send_money.recipient: the value came only from read_file ✓

The recipient came only from content the agent read. The gateway removes that call before the agent can run it and logs it. It adds no tokens.

The Prestige
CERTIFICATE — AgentDojo v1.2.2, muse-spark-1.3, live, Nov 2–3
optimized attacks: none 42/70 → Prestige 0/70 (7 pairs where they land, 10 runs each)
tasks done: 53/57 no gateway → 51/57 with the confirm step
cost / task: −40% (95% CI −47 to −32, guard on both sides)
time / task: −22% (guard adds ~0.3 ms per reply)
Spark Open on Baseten: 20/40 → 0/40, cost −33%

One honest certificate. Every attack that still got through is listed by its benchmark task ID, with counts, and the plan's misses are reported as misses.

Built and measured

Over 4,700 live runs on Meta's models behind these numbers, on Muse Spark through Meta's Model API and on Muse Spark Open through Baseten.

✓

The gateway works. OpenAI-compatible, with spend caps, SQLite call tracing, the guard and a confirm step.

✓

The test plan came first. Committed before any live run. One planned check missed its margin, and the docs say so.

✓

Muse resists the standard attacks. 0 of 352 worked with no guard. Optimized attacks from AutoDojo did get through, and Prestige stopped all of them.

✓

The known gap is published. A harmful message body sent to a real person gets through, because the guard checks where things go, not what they say.

Prior work: ROPE and CaMeL use the same origin idea. Prestige puts it in a drop-in gateway, ships it with cost savings in the same install, and measures both on Meta's models.
